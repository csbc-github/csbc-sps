# 掃描器功能說明

本文件說明 ThreeDScan 主畫面提供的三項掃描器相關功能，供向客戶說明系統能力與各功能意義。

主畫面標題列按鈕（由左至右）：**掃描參數**、**測試掃描**、**群組名稱**。

---

## 1. 背景說明

面掃描器（LJ-S8000）在現場通常透過 Navigator 調整各 Scan 程式的拍攝設定（曝光、光量、峰值處理等）。這些設定會依 **Scan 群組** 分開儲存，現場常稱「Scan 1」「Scan 2」…最多 16 組。

ThreeDScan 新增三項功能，讓操作人員可在本系統內：

- 檢視與調整各群組的拍攝參數  
- 在正式量測前預覽掃描效果  
- 為各群組設定易辨識的名稱  

減少僅依賴 Navigator 手動調參、以及重開設備後設定不易追溯的情況。

---

## 2. 名詞說明

| 名詞 | 說明 |
|------|------|
| **掃描器** | 產線上的單台面掃描設備（系統可管理一台或多台） |
| **群組** | 掃描器上的一組獨立拍攝設定，對應 Navigator 的 Scan 1～16，共 16 組 |
| **拍攝參數** | 影響掃描影像品質的設定，例如曝光時間、動態範圍、光量控制、峰值處理、死角補間、Y 方向間隔等 |
| **Save（儲存至控制器）** | 將調整後的設定永久寫入掃描器，斷電重開後仍保留 |
| **測試掃描** | 觸發一次掃描並顯示結果，用於確認目前設定下的成像效果 |

---

## 3. 功能一：掃描參數

### 功能意義

提供與 Navigator **拍攝參數** 對齊的調整介面，讓人員可在 ThreeDScan 內直接檢視、修改各群組的拍攝設定，並將確認後的設定 **儲存至掃描器**，同時在本系統保留一份備份，供日後查閱或還原參考。

### 可調整的項目

本功能涵蓋掃描器端的拍攝與輪廓相關設定，主要包括：

| 類別 | 項目 |
|------|------|
| 感光特性 | 動態範圍 |
| 光量設定 | 曝光時間、光量控制模式（手動／自動／SLOPE）、光量上下限 |
| 峰值處理 | 峰值檢測靈敏度、半透明體峰值處理 |
| 複數峰值處理 | 光暈過濾器（開關與強度）、峰值選擇 |
| 死角處理 | 死角資料插補方式 |
| 掃描間隔 | Y 方向間隔倍數 |

**Y 方向數據間隔（mm）** 僅供畫面顯示參考，不在此功能內修改。

### 目前不包含的項目

**PC 圖像過濾**（例如去除突起狀干擾、無效像素控制、輪廓插補控制等）屬於 Navigator 端設定，**不在本功能範圍內**，仍須於 Navigator 調整。

### 主要能力

- 依 **掃描器** 與 **群組** 分別管理拍攝參數  
- 從掃描器讀取目前設定至畫面  
- 將調整後的設定儲存至掃描器（永久生效）  
- 儲存成功後，於本系統保留該群組的參數備份  

### 使用時機（概念）

- 新工件或新製程需要調整曝光、峰值等拍攝條件時  
- 希望將現場調好的參數固定下來，避免重開設備後設定遺失時  
- 需要在 ThreeDScan 內統一管理各群組參數，減少反覆進出 Navigator 時  

### 注意事項

- 與 Navigator 操作的是**同一組**掃描器程式設定；兩邊同時修改同一群組時，**以最後儲存的一方為準**  
- 建議在透過本系統儲存參數時，**暫時關閉 Navigator 連線**，避免互相覆蓋  

---

## 4. 功能二：測試掃描

### 功能意義

在**不變更**掃描器上已永久儲存的設定前提下，針對指定掃描器與群組 **執行一次掃描**，並以 **3D 預覽** 顯示結果，供人員快速確認目前設定下的成像效果是否可接受。

### 主要能力

- 選擇掃描器與群組後執行單次掃描  
- 以 3D 方式預覽掃描結果  
- 顯示影像尺寸等基本資訊  

### 與「掃描參數」的差異

| | 掃描參數 | 測試掃描 |
|---|----------|----------|
| 目的 | 調整並**儲存**拍攝設定 | **預覽**目前設定下的掃描效果 |
| 是否變更永久設定 | 是（儲存後生效） | 否 |
| 輸出 | 更新掃描器設定與系統備份 | 3D 掃描預覽畫面 |

測試掃描使用的是該群組在掃描器上**已儲存**的設定。若在「掃描參數」中修改了數值但尚未儲存，測試掃描反映的仍是**修改前**的設定。

### 使用時機（概念）

- 調整參數並儲存後，想先確認掃描品質再投入正式量測  
- 比對不同群組在相同工件下的成像差異  
- 現場除錯時，快速確認掃描器連線與觸發是否正常  

---

## 5. 功能三：群組名稱

### 功能意義

為每台掃描器的 16 個群組設定 **自訂顯示名稱**，讓下拉選單與畫面標示更易辨識（例如「標準角鋼」「薄板驗證」「備用」），方便現場溝通與對照，**不改變**群組編號本身，也**不影響**各群組的拍攝參數數值。

### 主要能力

- 每台掃描器可獨立命名 16 個群組  
- 名稱顯示於「掃描參數」「測試掃描」等功能的群組選單（格式如：`4. 角鋼標準件`）  
- 未自訂時，系統提供預設名稱（群組一～群組十六）  

### 與拍攝參數的關係

| | 群組名稱 | 掃描參數 |
|---|----------|----------|
| 調整內容 | 群組的**顯示名稱** | 群組的**拍攝設定數值** |
| 是否影響掃描結果 | 否 | 是 |

### 使用時機（概念）

- 現場以工件類型、製程或用途區分各 Scan 群組時  
- 多人協作時，用名稱而非編號溝通（「用薄板那件設定」）  
- 對外說明或文件需要清楚標示各群組用途時
